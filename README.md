# Operator Overloading in C++

A C++ project focused on object-oriented programming and operator overloading.

## Classes

### 1. Fraction

A class for working with fractions.

**Implemented operations:**
- `+` — Addition
- `-` — Subtraction
- `*` — Multiplication
- `/` — Division

### 2. Complex

A class for working with complex numbers.

**Implemented operations:**
- `+` — Addition
- `-` — Subtraction
- `*` — Multiplication
- `/` — Division

### 3. Array

A class that implements a dynamic array.

**Features:**
- Dynamic memory allocation
- Default and parameterized constructors
- Copy constructor
- Destructor
- Copy assignment operator
- Filling and displaying array elements

**Overloaded operators:**

| Operator | Description |
|:---:|---|
| `+` | Concatenation of two arrays |
| `-` | Removal of elements from the end |
| `<<` | Output of array elements |
| `>>` | Input of array elements |
| `[]` | Access to an element by index |
| `()` | Returns the index of the maximum element |

**Type conversions:**

| Type | Description |
|:---:|---|
| `int` | Sum of positive elements |
| `double` | Smallest negative element |

## Technologies

- C++
- Object-Oriented Programming (OOP)
- Operator Overloading
- Dynamic Memory Management

## Purpose

This project was created as a practical exercise to improve my understanding of C++, operator overloading, constructors, destructors, dynamic memory allocation, and object-oriented programming.
